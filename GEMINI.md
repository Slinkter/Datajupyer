# Datajupyer

## Directory Overview
This repository contains educational materials, specifically Jupyter Notebooks and datasets, for learning Data Science and Python. It appears to be structured around two main versions or courses:
- **Version01:** A comprehensive 7-week Data Science program (likely from "Hacker School") covering Python basics, Scientific Python Stack, Data Exploration, Feature Engineering, Machine Learning, and Data Visualization.
- **Version02:** A "Data Science Course" by "thepycoach", focusing on practical applications with Pandas (Crash Course, Web Scraping, Data Filtering, Pivot Tables, Data Visualization) and Machine Learning (Text Classification with scikit-learn).

## Key Files & Directories
- `Version01/README.md`: Describes the 7-week Data Science program syllabus and graduation criteria.
- `Version02/README.md`: Contains links to external resources (Python cheat sheet) and references a Kaggle dataset used in the course.
- `Version01/` & `Version02/`: These directories contain numerous `.ipynb` (Jupyter Notebook) files, which are the primary instructional materials.
- `data/`, `datasets/`, and various `.csv`, `.xlsx`, `.sqlite`, `.h5` files: These are the datasets used within the notebooks for exercises and projects.

## Usage
This project is meant to be used interactively via Jupyter Notebook or JupyterLab.
Users should navigate to the desired lesson folder and open the corresponding `.ipynb` file to read the lessons and execute the Python code cells.
You will likely need a Python environment with data science libraries installed (such as `pandas`, `numpy`, `scikit-learn`, `matplotlib`, `seaborn`, `beautifulsoup4`, etc.) to run the notebooks successfully. There isn't an explicit `requirements.txt` file provided, so dependencies must be inferred or installed as needed when running individual notebooks.
