### **2. Notas Clave**

#### **A. Código Robusto: Manejo de Excepciones**
*   **Excepciones:** Son errores que ocurren durante la ejecución. Python permite "manejarlos" para que el programa no se detenga.
*   **Bloque `try...except`:** Es la herramienta principal. El código que podría fallar va en el bloque `try`. El manejo del error va en el `except`.
    *   `else`: Se ejecuta si `try` **no** lanza una excepción.
    *   `finally`: Se ejecuta **siempre**, con o sin excepción. Ideal para limpieza (ej. cerrar un archivo).
*   **Filosofía EAFP vs. LBYL:**
    *   **LBYL (Mira antes de saltar):** Comprobar condiciones antes de actuar (ej. `if key in dict...`).
    *   **EAFP (Es más fácil pedir perdón que permiso):** Actuar directamente y capturar la excepción (`try...except`). Este es el **estilo idiomático y preferido en Python** por ser más limpio y eficiente.

#### **B. Código Eficiente y Conciso**
*   **Comprehensions:** Sintaxis compacta para crear colecciones.
    *   List: `[x**2 for x in range(10)]`
    *   Dict: `{x: x**2 for x in range(5)}`
    *   Set: `{letra for letra in "palabra"}`
*   **Generadores:** Crean iteradores "perezosos" que producen valores bajo demanda, optimizando drásticamente el uso de memoria.
    *   **Expresión Generadora:** `(x**2 for x in range(10))`. Usa paréntesis.
    *   **Función Generadora:** Una función que usa la palabra clave `yield` para devolver un valor y pausar su estado.
*   **Funciones Lambda:** Pequeñas funciones anónimas de una sola expresión. Se usan principalmente como argumentos para otras funciones (ej. `key` en `sorted`, o con `map` y `filter`).
    ```python
    sorted(lista, key=lambda item: item['edad'])
    ```

#### **C. Código Organizado y Distribuible**
*   **Módulo:** Cualquier archivo `.py`.
*   **Paquete:** Una carpeta que contiene módulos y un archivo `__init__.py` (puede estar vacío). Permite agrupar código relacionado.
*   **Estructura de Proyecto:** Se recomienda una estructura estándar (código fuente en una carpeta, tests en otra) para facilitar la mantenibilidad.
*   **Distribución (Estándar 2025):** Para que un paquete sea instalable con `pip`, la configuración se define en un archivo **`pyproject.toml`**. Este enfoque moderno reemplaza al antiguo `setup.py`.

### **4. Ejemplos Simplificados**

*   **Manejo de Errores (EAFP):**
    ```python
    mi_dict = {}
    try:
        print(mi_dict["clave_desconocida"])
    except KeyError:
        print("La clave no existe.")
    ```
*   **List Comprehension:**
    ```python
    numeros_pares = [i for i in range(10) if i % 2 == 0]
    ```
*   **Generador con `yield`:**
    ```python
    def cuenta_hasta_tres():
        yield 1
        yield 2
        yield 3
    ```

### **5. Analogías**

*   **Manejo de Excepciones:** Conducir por una ruta (bloque `try`). Si se pincha una rueda (excepción), te detienes y la cambias (bloque `except`). El bloque `finally` sería como recoger tus herramientas al final, sin importar si pinchaste o no.
*   **Generador vs. Lista:** Un generador es como un grifo de agua; solo obtienes agua cuando lo abres y solo la cantidad que necesitas. Una lista es como llenar una piscina entera de golpe; tienes toda el agua disponible, pero ocupa mucho espacio.
*   **`pyproject.toml`:** La "caja" de un producto de IKEA. Contiene el nombre del mueble, la lista de piezas (dependencias) y las instrucciones de montaje (backend de construcción).

### **7. Ejercicios Recomendados**

1.  **Excepciones:** Escribe una función que reciba un nombre de archivo, intente leerlo y devuelva su contenido. Debe usar `try...except` para manejar la excepción `FileNotFoundError`, devolviendo un mensaje de error si el archivo no existe.
2.  **Comprehensions:** Dada una lista de precios `[100, 200, 55, 80]`, usa una `dict comprehension` para crear un diccionario que mapee cada precio a su valor con un 21% de IVA añadido.
3.  **Generadores:** Crea una función generadora `rango_invertido(n)` que produzca números desde `n-1` hasta `0`.
4.  **Lambdas:** Usa la función `filter` y una `lambda` para obtener solo las palabras de más de 5 letras de una lista de palabras.
5.  **Paquetes:** Estructura una carpeta `mi_calculadora` como un paquete, con un módulo `operaciones.py` dentro que tenga una función `restar`. Desde un script fuera de la carpeta, importa y usa la función `restar`.
