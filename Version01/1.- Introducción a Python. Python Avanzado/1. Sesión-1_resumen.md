### **2. Notas Clave**

#### **A. Entorno de Desarrollo**
*   **Anaconda:** Es una distribución de Python para ciencia de datos que incluye el lenguaje, cientos de librerías y herramientas como el gestor de paquetes `conda`.
*   **Entornos Virtuales:** `conda` permite crear "espacios aislados" para cada proyecto, asegurando que las versiones de las librerías no entren en conflicto. Se crea con `conda create -n <nombre> python=<version> [librerias]`.
*   **Jupyter Notebook:** Es una aplicación web interactiva que permite combinar código ejecutable, texto con formato (Markdown), ecuaciones (LaTeX) y visualizaciones en un solo documento. Es el estándar para la exploración de datos.

#### **B. Fundamentos de Python**
*   **Sintaxis Básica:**
    *   La **indentación** (4 espacios) es obligatoria y define los bloques de código (bucles, funciones, etc.).
    *   Los **comentarios** se escriben con el símbolo `#`.
*   **Variables y Tipos de Datos:**
    *   **Variables:** Son nombres que apuntan a objetos en memoria. Python tiene tipado dinámico (no se declara el tipo).
    *   **Tipos Numéricos:** `int` (enteros), `float` (decimales).
    *   **Booleanos:** `True` y `False`.
    *   **Strings (`str`):** Secuencias de caracteres de texto. Son inmutables.
*   **Estructuras de Datos Fundamentales:**
    *   **Listas (`list`):** Colección ordenada y **mutable** de elementos. Se definen con `[]`.
    *   **Tuplas (`tuple`):** Colección ordenada e **inmutable**. Se definen con `()`. Son más rápidas y seguras para datos que no deben cambiar.
    *   **Diccionarios (`dict`):** Colección no ordenada de pares `clave: valor`. Optimizados para búsquedas por clave. Se definen con `{}`.
*   **Control de Flujo:**
    *   **Condicionales:** `if`, `elif`, `else` para ejecutar código según se cumpla una condición.
    *   **Bucle `for`:** Para iterar sobre los elementos de una secuencia (ej. una lista).
    *   **Bucle `while`:** Para repetir un bloque de código mientras una condición sea verdadera.

### **4. Ejemplos Simplificados**

*   **Asignación de variable:**
    ```python
    nombre = "Ana"
    edad = 25
    ```
*   **Creación de una lista:**
    ```python
    compras = ["leche", "pan", "huevos"]
    ```
*   **Bucle `for` simple:**
    ```python
    for item in compras:
        print(item)
    ```
*   **Condicional `if/else`:**
    ```python
    if edad >= 18:
        print("Es mayor de edad.")
    else:
        print("Es menor de edad.")
    ```

### **5. Analogías**

*   **Variable:** Una etiqueta que le pones a una caja para saber qué contiene.
*   **Lista:** Un archivador donde puedes añadir, quitar o reordenar las carpetas en cualquier momento.
*   **Tupla:** Un documento histórico enmarcado en una vitrina; puedes leerlo y referenciarlo, pero no puedes alterarlo.
*   **Diccionario:** Una agenda de contactos; buscas a una persona por su nombre (la clave) y obtienes su número de teléfono (el valor).
