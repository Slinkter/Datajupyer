### **2. Notas Clave**

#### **A. Funciones: Bloques de Lógica Reutilizables**
*   **Definición:** Se crean con la palabra clave `def`, seguida del nombre, paréntesis `()` para los argumentos y dos puntos `:`. El cuerpo de la función va indentado.
    ```python
    def saludar(nombre, saludo="Hola"):
        return f"{saludo}, {nombre}!"
    ```
*   **Docstrings:** Un string `"""..."""` al inicio de la función sirve como documentación, explicando qué hace.
*   **Argumentos Flexibles:**
    *   **`*args`**: Agrupa un número variable de argumentos **posicionales** en una **tupla**. Útil para funciones que deben procesar una cantidad indeterminada de ítems.
    *   **`**kwargs`**: Agrupa un número variable de argumentos de **palabra clave** en un **diccionario**. Ideal para funciones que aceptan muchas opciones de configuración.
*   **Decoradores:** Son funciones que modifican a otras funciones. Se usan con la sintaxis `@nombre_decorador`. Permiten añadir funcionalidades (como medir tiempo de ejecución, verificar permisos, logging) de forma limpia y reutilizable sin alterar el código de la función original.

#### **B. Programación Orientada a Objetos (POO)**
*   **Paradigma:** Utiliza **objetos** para representar entidades que agrupan datos (**atributos**) y comportamientos (**métodos**).
*   **Clase (`class`):** Es la **plantilla** o molde para crear objetos. Define los atributos y métodos comunes.
*   **Objeto:** Es una **instancia** concreta de una clase, con su propio estado (valores en sus atributos).
*   **Componentes Clave de una Clase:**
    *   `__init__(self, ...)`: El método **constructor**. Se llama automáticamente al crear un objeto (ej. `coche = Vehiculo(...)`). La variable `self` siempre se refiere a la instancia actual del objeto.
    *   **Atributos de Instancia:** Datos únicos para cada objeto. Se definen dentro de `__init__` con `self.atributo = valor`.
    *   **Atributos de Clase:** Datos compartidos por **todas** las instancias de la clase. Se definen directamente dentro del `class`.
    *   **Métodos:** Funciones que pertenecen a la clase y operan sobre los datos del objeto (siempre reciben `self` como primer argumento).
*   **`@property`:** Un decorador que convierte un método en un "atributo de solo lectura". Permite ejecutar lógica para calcular un valor, pero se accede a él como si fuera un atributo normal, sin paréntesis `()`.

### **4. Ejemplos Simplificados**

*   **Función con `*args`:**
    ```python
    def sumar_todo(*numeros):
        return sum(numeros)

    print(sumar_todo(1, 2, 3, 4)) # Devuelve 10
    ```
*   **Clase simple:**
    ```python
    class Producto:
        def __init__(self, nombre, precio):
            self.nombre = nombre
            self.precio = precio
        
        def mostrar_info(self):
            return f"{self.nombre}: ${self.precio}"
    ```
*   **Creación y uso de un objeto:**
    ```python
    producto1 = Producto("Laptop", 1200)
    print(producto1.mostrar_info()) # Imprime "Laptop: $1200"
    ```

### **5. Analogías**

*   **Función:** Una máquina expendedora. Los argumentos son el dinero y el código del producto que introduces, los pasos internos son la mecánica de la máquina, y el `return` es el refresco que te entrega.
*   **Clase:** La receta y el diseño de una galleta (ej. "galleta con chips de chocolate"). Define los ingredientes (atributos) y cómo se hornea (métodos).
*   **Objeto:** Cada galleta individual que horneas siguiendo esa receta. Cada una es una "instancia" de la galleta, con su propio nivel de cocción y número de chips de chocolate.
*   **Decorador:** El control de calidad que envuelve el proceso de empaquetar un producto. No cambia el producto, pero le añade una etiqueta de "revisado" antes de entregarlo.

### **6. Resumen Final**

Esta sesión proporciona las herramientas para escribir código Python más allá de simples scripts. Las **funciones** nos permiten crear lógica modular y reutilizable, mientras que la **Programación Orientada a Objetos** nos da un paradigma completo para diseñar sistemas complejos, modelando el mundo a través de **clases** que actúan como plantillas para **objetos** con estado y comportamiento propios.

1.  **Función con `**kwargs`:** Escribe una función `crear_perfil` que tome un argumento posicional `nombre` y luego acepte cualquier número de argumentos de palabra clave (como `edad`, `ciudad`, `profesion`). La función debe imprimir un perfil de usuario bien formateado.
2.  **Decorador:** Crea un decorador `@solo_positivos` que verifique si todos los argumentos numéricos pasados a una función son positivos. Si alguno es negativo, debe imprimir un error; de lo contrario, debe ejecutar la función. Úsalo para decorar una función `multiplicar(a, b)`.
3.  **Clase:** Diseña una clase `CuentaBancaria` con atributos `titular` y `saldo`.
4.  **Métodos:** Añade a la clase `CuentaBancaria` los métodos `depositar(cantidad)` y `retirar(cantidad)`. El método `retirar` no debe permitir que el saldo se vuelva negativo.
5.  **Propiedad:** Añade una `@property` llamada `saldo_disponible` que devuelva un string formateado como `"$1,234.56"`.
