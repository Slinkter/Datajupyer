### **2. Notas Clave**

#### **A. NumPy (Numerical Python)**
*   **`ndarray` (Arreglo N-dimensional):** Es el objeto central de NumPy.
    *   **Homogéneo:** Todos sus elementos deben ser del mismo tipo (ej. todos `int64` o `float64`).
    *   **Eficiente:** Al ser denso y de tipo estático, ocupa menos memoria y permite operaciones mucho más rápidas que las listas de Python.
*   **Vectorización:** Es la característica más importante de NumPy. Las operaciones (suma, multiplicación, etc.) se aplican a todos los elementos de un arreglo a la vez, sin necesidad de escribir bucles `for` en Python. Este "empujar el bucle" a código C compilado es la principal fuente de su velocidad.
*   **Creación de Arreglos:** Se pueden crear desde listas (`np.array()`) o con funciones especializadas como `np.arange()`, `np.zeros()`, `np.ones()`, `np.linspace()`.
*   **Indexación y Slicing:**
    *   **Slicing (ej. `arr[5:10]`):** Crea **vistas** (`views`), no copias. Una modificación en la vista afecta al arreglo original. Esto es un comportamiento diferente al de las listas de Python y es clave para la eficiencia.
    *   **Fancy Indexing (ej. `arr[[0, 5, 7]]`):** Usar una lista o un array de índices para seleccionar elementos. Esto siempre crea una **copia** (`copy`) de los datos.
*   **Broadcasting:** Un conjunto de reglas que permite a NumPy realizar operaciones aritméticas en arreglos de diferentes formas de manera inteligente, "estirando" virtualmente el arreglo más pequeño para que coincida con el más grande.

#### **B. Pandas (Panel Data Analysis)**
*   Construido sobre NumPy, añade estructuras de datos y herramientas de análisis de alto nivel.
*   **Estructuras de Datos:**
    *   **`Series`:** Un arreglo 1D **etiquetado**. Es como una columna de una hoja de cálculo. Tiene un `índice` que no tiene por qué ser numérico.
    *   **`DataFrame`:** Una tabla 2D **etiquetada** (filas y columnas). Es la estructura de datos principal y el caballo de batalla en Pandas. Se puede pensar en él como un diccionario de `Series`.
*   **Inspección Básica:** Métodos esenciales para entender un DataFrame:
    *   `.head() / .tail()`: Ver las primeras/últimas filas.
    *   `.info()`: Resumen técnico (tipos de datos, memoria, valores no nulos).
    *   `.describe()`: Resumen estadístico de las columnas numéricas.
*   **Selección de Datos (CRÍTICO):**
    *   **`.loc`**: Selección por **ETIQUETA** (nombre de la fila o columna). Es inclusivo en los rangos.
    *   **`.iloc`**: Selección por **POSICIÓN** entera (índice numérico). Exclusivo en los rangos, como las listas de Python.
    *   **Indexación Booleana:** Filtrar filas usando una condición que devuelve una Serie de `True`/`False`. Ej: `df[df['edad'] > 30]`.

### **4. Ejemplos Simplificados**

*   **Operación vectorizada en NumPy:**
    ```python
    import numpy as np
    arr = np.array([10, 20, 30])
    arr_con_iva = arr * 1.21 
    # Resultado: array([12.1, 24.2, 36.3])
    ```
*   **Creación de un DataFrame:**
    ```python
    import pandas as pd
    datos = {'Nombre': ['Ana', 'Luis'], 'Edad': [28, 34]}
    df = pd.DataFrame(datos)
    ```
*   **Filtro booleano en Pandas:**
    ```python
    df_mayores_30 = df[df['Edad'] > 30]
    ```

### **5. Analogías**

*   **NumPy Array vs. Lista de Python:** Un array de NumPy es una formación militar perfectamente alineada; todos visten el mismo uniforme y responden a una orden al unísono (vectorización). Una lista de Python es una multitud en una plaza; son flexibles y diversos, pero para darles una orden a todos, tienes que ir uno por uno.
*   **DataFrame de Pandas:** Una hoja de cálculo de Excel con superpoderes. Puedes filtrar, ordenar, agrupar y hacer cálculos complejos en toda la tabla con comandos simples.
*   **`.loc` vs. `.iloc`:** `.loc` es buscar a una persona en un directorio por su nombre (`df.loc['Ana']`). `.iloc` es buscar a la primera persona en la lista (`df.iloc[0]`), sin importar cómo se llame.
